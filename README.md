# Movie Universe

A movie-themed website developed as a third-semester university project, focusing on front-end development and responsive web design.

## Overview

Movie Universe is a website slicing project that demonstrates the implementation of a movie-themed user interface using modern web technologies. The project focuses on translating design concepts into a structured, responsive, and user-friendly website.

## Features

- Responsive website layout
- Movie-themed user interface
- Structured content presentation
- Modern and consistent styling
- Interactive front-end elements

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Getting Started

Clone the repository:

```bash
git clone https://github.com/nurkalamabdurrahman/movie-universe-slicing.git
```

Open the project folder and launch `index.html` in your browser.
